# AWS-IAM-Users-Groups-Lab
AWS IAM user, group, and permission management practical
## Result

The AWS IAM Users and Groups Management practical demonstrates the assignment of users to specific groups and the configuration of permissions using IAM policies.

- **user-1:** S3 read-only access through the S3-Support group.
- **user-2:** EC2 read-only access through the EC2-Support group.
- **user-3:** Permission to describe, start, and stop EC2 instances through the EC2-Admin group.

Thus, the practical illustrates role-based access control and the principle of least privilege in AWS IAM.
